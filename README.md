# 拉格朗日考勤

《无尽的拉格朗日》联盟考勤的本地化工具。上传一张考勤截图，自动识别「谁来了、谁没来」。

纯本地运行，不连接游戏、不读取游戏数据，零封号风险。免费、开源。

## 本次更新：新版星图（舰队所属人名）截图识别

游戏 2026-09 更新后，星图会直接把**舰队所属人名**标在舰队旁边，打卡截图可以更短。本版新增：

- **新版星图截图识别**：一张截不全、或名字叠在一起时，把画面放大/拖动让名字分开，多截几张一次上传，自动合并；
- **同一批截图 = 一场考勤**，照样输出到场/未到场表，并继续累积缺席统计；
- **重叠名字自动拆**：两个名字挤成一串、中间没有任何分隔时，也能按名册拆开、各算一人（比如 OCR 读到一串“星海远航者月下客”，而名册里是“星海远航者”和“月下客”两个名字）。

本版**只支持截图**；录屏（视频）自动识别、繁荣度、权限分发、自动更新等属于完整版。

> 这是**免费测试版**，主要用来收集识别问题：谁漏了、多了、认错了，按 [反馈与问题收集.md](反馈与问题收集.md) 的格式发给作者即可。

## 它能做什么

- 识别考勤截图里的玩家名字（本地 OCR，无需联网、无需密钥）
- **两种活动截图都支持**：纵向的「纯名字名单图」，以及集合点「星图图片」——工具自动判断类型
- 对比你的名册，输出「到场 / 未到场」清单
- **多次考勤自动累积**：每一次识别都会记录，自动统计每个成员的「连续缺席」「赛季累计缺席」，并提示该清退的人（**连续缺席 ≥3 次** 或 **赛季累计缺席 ≥8 次**，累计非连续）——中途新加入的成员，入盟前的场次不计入缺勤
- 生成 CSV 和 Excel 两种格式，直接发给队友或自己留存
- 越用越准：每次识别都会累积样本，形近字、新名字识别更稳定

## 适用场景

- 集合点、活动打卡后，快速统计哪些成员到场
- 小队出勤记录留存与核对

## 安装

> 本仓库是**源码版**，没有打包好的 exe——需要你自己装 Python、跑命令（所以它更适合稍微会折腾的人）。不想碰命令行的，看文末「更完整的考勤方案」。

需要 Python 3.9+（Windows 安装时记得勾选 **Add Python to PATH**）。

```bash
pip install -r requirements.txt
```

识别模型（`ocr_models_v6/`，约 133MB）**已随仓库提供**，不用另外下载；装完依赖即可完全离线运行。

### 先跑起来（网页界面）

```bash
python attendance_gui.py
```

会自动打开浏览器，照界面上的三步操作就行（建名册 → 考勤打卡 → 看结果）。
Windows 用户也可以直接双击 `启动.bat`（首次会自动装依赖）。

## 使用

### 第一步：建立名册（二选一）

**方式 A：全盟截图一键生成（推荐，不用手填）**

截一张联盟成员列表截图（含「玩家名 + 小队」列，或纯名字列表均可），运行：

```bash
python attendance.py build-roster 全盟截图.png
```

会自动生成 `roster.csv`（玩家名 + 小队）。生成后请核对一眼：OCR 偶有形近字误差，改错字即可。

> **不会丢人**：`build-roster` 默认与已有 `roster.csv` **合并追加**，分多次传图也不会覆盖之前的人。
> 要彻底重来，加 `--overwrite`：`python attendance.py build-roster 全盟截图.png --overwrite`

**方式 B：手动填写**

直接编辑 `roster.csv`，按 `玩家名,小队` 格式逐行填入成员（适合名单很少、或不想截图的情况）。

**用网页界面（`python attendance_gui.py`）的话**：第 1.5 步「手动编辑 / 录入名册」卡片里可以直接在网页增删改名字和小队并保存；想纯手填不截图也行。

### 第二步：考勤打卡

每次活动后，截「活动到场截图」——可以是纵向排列玩家名的**纯名字名单图**，也可以是集合点**星图图片**（工具自动判断类型）。游戏里一张截图基本截不全：全盟名单要分多张（或长截图），集合点星图更要每队各截一张才覆盖全员，所以**可以一次传多张**，运行：

```bash
python attendance.py recognize 截图1.png 截图2.png 截图3.png
```

多张图会**自动合并到场名单**（同一玩家只计一次，不会互相覆盖）；纯名字名单和星图混着传也行。

**新版星图（舰队所属人名）**：名字重叠时先放大/移动让名字分开，再多截几张，然后指定 `--type owner_labels`：

```bash
python attendance.py recognize 星图1.png 星图2.png --type owner_labels
```

网页界面里对应的是「第 2.5 步 · 新版星图（舰队所属人名）」，同样支持一次多选。

> 注：开源版识别**图片/截图**。**录屏视频**自动识别是完整版能力，详见文末。

工具会自动比对名册，列出谁到场、谁没来——你不用一个个肉眼核对。

每次识别都会自动累积历史（存到 `history/attendance.csv`，不联网、不上传）。**多记几次之后**，表格里会自动多出「连续缺席」「累计缺席」「建议清退」三列，帮你一眼看出谁该清退：

- **连续缺席 ≥3 次** → 建议清退（注意是「连续」，偶尔漏一两次不踢）
- **赛季累计缺席 ≥8 次**（累计非连续）→ 也建议清退
- 中途新加入的成员，入盟前的场次不算缺勤，不会被冤枉

> 只想本次看结果、不想累积历史？加 `--no-history` 即可。

### 第三步：查看结果

- `attendance_日期.csv` —— 玩家名 / 小队 / 状态(到场·未到场·疑似) / OCR文本 / 相似度 / 连续缺席 / 累计缺席 / 建议清退
- `attendance_日期.xlsx` —— 同一内容的表格

盯着状态为「未到场」或「建议清退」的几个人去催打卡就行。

## 案例库（可选）

本工具会记录每次识别的样本，帮助提升识别准确率。你可以把样本导出、分享给作者或社区，大家一起把识别做得更准：

```bash
python attendance.py cases --stats          # 查看已累积的样本数
python attendance.py cases --export case.zip # 导出样本包
```
