# 拉格朗日考勤

《无尽的拉格朗日》联盟考勤的本地化工具。上传一张考勤截图，自动识别「谁来了、谁没来」。

纯本地运行，不连接游戏、不读取游戏数据，零封号风险。免费、开源。

## 它能做什么

- 识别考勤截图里的玩家名字（本地 OCR，无需联网、无需密钥）
- 对比你的名册，输出「到场 / 未到场」清单
- 生成 CSV 和 Excel 两种格式，直接发给队友或自己留存
- 越用越准：每次识别都会累积样本，形近字、新名字识别更稳定

## 适用场景

- 集合点、活动打卡后，快速统计哪些成员到场
- 小队出勤记录留存与核对

## 安装

需要 Python 3.9+。

```bash
pip install -r requirements.txt
```

（OCR 模型首次运行会自动下载，之后可离线使用。）

## 使用

### 第一步：建立名册（二选一）

**方式 A：全盟截图一键生成（推荐，不用手填）**

截一张联盟成员列表截图（含「玩家名 + 小队」列，或纯名字列表均可），运行：

```bash
python attendance.py build-roster 全盟截图.png
```

会自动生成 `roster.csv`（玩家名 + 小队）。生成后请核对一眼：删掉不是成员的行、补上空缺的小队即可。

**方式 B：手动填写**

直接编辑 `roster.csv`，按 `玩家名,小队` 格式逐行填入成员（适合名单很少、或不想截图的情况）。

### 第二步：考勤打卡

每次活动后，截一张「到场成员截图」（纵向排列玩家名、没有数字列的那类），运行：

```bash
python attendance.py recognize 你的截图.png
```

工具会自动比对名册，列出谁到场、谁没来——你不用一个个肉眼核对。

### 第三步：查看结果

- `attendance_日期.csv` —— 玩家名 / 小队 / 状态(到场·未到场·疑似) / OCR文本 / 相似度
- `attendance_日期.xlsx` —— 同一内容的表格

盯着状态为「未到场」的几个人去催打卡就行。

## 案例库（可选）

本工具会记录每次识别的样本，帮助提升识别准确率。你可以把样本导出、分享给作者或社区，大家一起把识别做得更准：

```bash
python attendance.py cases --stats          # 查看已累积的样本数
python attendance.py cases --export case.zip # 导出样本包
```

## 关于更完整的考勤方案
