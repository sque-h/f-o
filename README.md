# 拉格朗日考勤 · 开源版（考勤1.0 阉割引流版）

《无尽的拉格朗日》联盟考勤的**开源免费版**。纯本地识别，不碰游戏数据，零封号风险。

> 这是「考勤1.0」的**阉割引流版**：只留考勤核心（谁来了谁没来），用来尝鲜和引流。
> 真正好用的完整版（全格式 + 更准识别 + 人工确认 + 赛季更新）和高端管家套餐是**付费**的，见文末。

## 能做什么 / 不能做什么

| 能做的（本开源版） | 不能做的（付费完整版才有） |
|---|---|
| 纯本地 OCR 识别玩家名（零密钥、离线） | 腾讯云高精度 OCR |
| 单格式：纯名字考勤截图 → 谁来了谁没来 | 成员列表/集合点/视频等多种格式 |

| 案例导出回传作者，喂中心库 | 自动分类、自动确认、自动化流程 |

## 安装

需要 Python 3.9+。

```bash
cd lagrange-attendance-open
pip install -r requirements.txt
```

（RapidOCR 模型会随包自动准备，首次运行会下载一次，之后离线。）

## 用法

### 1. 识别一张考勤截图（谁来了谁没来）

把你的「纯名字考勤截图」（纵向排列一堆玩家名、没有数字列的那类）准备好，运行：

```bash
python attendance.py recognize 你的截图.png
```

会生成：
- `attendance_YYYY-MM-DD.csv` —— 玩家名 / 小队 / 状态(到场·未到场·疑似) / OCR文本 / 相似度
- `attendance_YYYY-MM-DD.xlsx` —— 同一内容的本地表
- 自动往 `cases/` 累积一条案例（喂识别准确率）

用自己的名册替换 `roster.csv`（只留「玩家名,小队」两列，不要繁荣度列）。

### 2. 案例库（越肥越准，还能喂作者的护城河）

```bash
python attendance.py cases --stats          # 看本地累积了多少样本
python attendance.py cases --export case.zip # 导出匿名案例包
```

把 `case.zip` 发给作者（GitHub: **sque-h**），作者合并进全联盟共享案例库，
在完整版/管家里给你更准的识别。
